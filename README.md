## [TestSphare](https://github.com/Sahirullah/MyTestSphareProject)


**TestSphare** is a web-based educational platform designed to provide students with easy access to academic resources, including **notes, handouts, assignments, past papers, quizzes, books, and exam practice materials**.

The platform is built with modern frontend technologies and focuses on providing a simple, responsive, and user-friendly learning experience.

## Features

* 📚 Notes, handouts, books, and study materials
* 📝 Assignments and past papers
* 🧠 Online exam practice and quizzes
* 🔎 Resource search functionality
* 📱 Responsive design for desktop and mobile
* 🌙 Light and dark theme support
* 📰 Educational blogs and learning resources
* ⚡ Fast page loading with React lazy loading

## Tech Stack

* **React.js**
* **Vite**
* **JavaScript (ES6+)**
* **HTML5 & CSS3**
* **React Router**
* **Context API**
* **Vercel** for deployment

## Project Structure

```text
src/
├── components/    # Reusable UI components
├── pages/         # Application pages
├── data/          # Educational and exam data
├── context/       # Application context
├── assets/        # Images and static assets
└── App.jsx        # Main application and routing
```
